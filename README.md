# GreenLeaf Grocers

Inventory & Sales Management System with Analytics Dashboard.

## Project status
Step 1: Project structure and planning.

## Planned technology stack
- Python and Flask
- SQLite and SQLAlchemy
- HTML, CSS, Bootstrap, JavaScript
- Pandas, NumPy and Plotly
- Pytest

## Planned modules
- Authentication with admin and cashier roles
- Product and inventory management
- Billing and automatic stock deduction
- Low-stock and near-expiry alerts
- Sales and inventory analytics
- CSV import/export
- Automated tests
